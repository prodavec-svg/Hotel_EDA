# Hotel Booking EDA

Исследовательский анализ спроса и отмен бронирований в городском и курортном отелях: сезонность, стоимость, длительность проживания, клиенты и каналы продаж.

## Структура проекта

```text
Hotel_EDA/
├── data/
│   └── raw/                   # Исходные данные и служебные файлы загрузчика
│       └── hotel_bookings.csv
├── notebooks/
│   └── 01_hotel_eda.ipynb     # Исследовательские вопросы и анализ
├── .gitignore
├── README.md
└── requirements.txt
```

Исходные данные хранятся в `data/raw/` без изменений. Ноутбуки находятся в `notebooks/`. По мере появления повторно используемого кода и результатов можно добавить `src/` и `reports/`.

## Запуск

Используйте отдельное Python-окружение с зависимостями из `requirements.txt`. Для установки в выбранное окружение:

```bash
python -m pip install -r requirements.txt
```

Откройте `notebooks/01_hotel_eda.ipynb` в VS Code с поддержкой Jupyter либо запустите из корня проекта:

```bash
python -m jupyterlab
```

Выберите ядро созданного окружения и выполняйте ячейки по порядку. Путь к данным определяется при запуске как из корня проекта, так и из `notebooks/`.

## Данные

Идентификатор набора в Kaggle: `jessemostipak/hotel-booking-demand`.

Если `data/raw/hotel_bookings.csv` уже существует, ноутбук читает локальный файл. Если файл отсутствует, он загружается через `kagglehub`; для этого нужен интернет. Исходные CSV и служебные файлы загрузчика исключены из Git.

Локальные настройки VS Code зависят от компьютера и также исключены из Git.
